Drop your CodeChef certificate images in this folder.

The file name (without extension) must match the `file` value of that
certificate in src/data/codechef.js, for example:
  sql-at-work.jpg
  py-practise.jpg
  c-learn.jpg

The extension can be png, jpg, jpeg or webp. No code changes are needed:
when a matching file exists, that certificate's "View Certificate" button
opens the image inside the site instead of the CodeChef page.
